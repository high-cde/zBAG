Componenti inclusi

Vault coreStruttura account e saldo dichiarati nel sorgente; nessuna derivazione reale di chiavi.
TransazioniInterfaccia di firma/verifica dimostrativa; non adatta a firmare fondi reali.
Ledger e reteStub di esempio; non sincronizza una blockchain o peer reali.

Prossimo passo tecnico

Per un wallet utilizzabile servono un runtime/browser build verificabile, primitive crittografiche corrette, rete e RPC attendibili, gestione sicura delle chiavi e test indipendenti. GitHub Pages ospita solo i file statici.
